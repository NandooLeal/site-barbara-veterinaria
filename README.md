# Site da Bárbara Sackser

Primeira versão em HTML, CSS e JavaScript, sem framework e sem etapa de build.

## Abrir e editar

1. Abra a pasta no VS Code.
2. Abra `dist/index.html` no navegador. Se preferir atualização automática, use a extensão Live Server no VS Code.
3. Edite os textos em `dist/index.html`, o visual em `dist/styles.css` e o menu em `dist/script.js`.

As fontes Playfair Display e Montserrat são carregadas pelo Google Fonts e precisam de conexão. Se não carregarem, o navegador usa Georgia e Arial.

## Fotografia profissional

A seção “Sobre a Bárbara” tem uma área identificada como fotografia em breve. Não foi usada uma fotografia de outra pessoa.

Salve a foto como `dist/assets/barbara.jpg`. No `index.html`, substitua a `div` inteira com classe `portrait-placeholder` pelo elemento `img` fornecido no comentário logo acima dela. A classe `portrait` já define tamanho e recorte para computador e celular.

## Publicar em outra hospedagem

Envie o conteúdo da pasta `dist` para qualquer hospedagem de sites estáticos. O arquivo `.openai/hosting.json` é usado apenas pela hospedagem Sites e não é necessário em outros provedores.
